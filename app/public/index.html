Check Point 01 - Grupo 1

Toolchain OWASP · Pipeline tradicional

As quatro frentes do pipeline

SAST · Semgrep

Analisa o código-fonte próprio (white-box).

Estágio: Code / Build · App rodando: não

SCA · Dependency-Check

Analisa dependências de terceiros e licenças.

Estágio: Build · App rodando: não

IaC · Checkov

Analisa Terraform, CloudFormation, K8s, Docker e Helm.

Estágio: Code / Build / Deploy · App rodando: não

DAST · OWASP ZAP

Ataca a aplicação em execução (black-box).

Estágio: Test / Release · App rodando: sim
SAST não é SCA. SAST olha o código que a sua equipe escreveu. SCA olha as dependências de terceiros que você trouxe para dentro.
Shift-left não elimina o DAST. Ele é o único que exige a aplicação no ar.
